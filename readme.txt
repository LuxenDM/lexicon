Lexicon is a dictionary-styled translation library for Vendetta Online plugins. This library helps other plugins offer easy translation service to its users based on their locale configuration.

Lexicon supercedes the old Babel library. You can download and use Lexicon directly, but it is meant to be bundled with other mods. The latest version of Lexicon is offered with Neoloader itself.

Lexicon requires Neoloader or another LME provider to function.
